# Chloe — полное описание проекта

Chloe — личный голосовой ИИ-ассистент в стиле Jarvis. Вы говорите «Хлоя, …», она понимает задачу,
**сама делает всё на компьютере** и отвечает голосом. Файлы присылать ей не нужно — она сама ищет, скачивает,
создаёт, перемещает и удаляет их, а каждое изменение можно отменить.

На экране — её **живой мозг**: сфера из частиц, внутри — нейроны. Каждый навык, каждое воспоминание и каждый
предмет из вашего мира (программа, сайт, папка, человек) — отдельный нейрон. Светится только то, что сейчас реально
работает. Принцип — **ничего не скрыто**: всё, что она услышала, сказала и сделала, видно и управляемо.

Коротко про запуск — в `README.md`, устройство кода — в `docs/ARCHITECTURE.md`, что сделано и что дальше — в `docs/ROADMAP.md`.

## 2. Как Chloe работает (по шагам)

1. **Слышит.** Микрофон открыт всегда. Слово «Хлоя» она узнаёт **сама, без интернета** (Vosk); в Google на распознавание
   уходит только сказанное ей. После её ответа 30 секунд можно говорить без «Хлоя». Дослушивает фразу с паузами до конца.
2. **Думает двумя мозгами.** Простое — быстрая модель, сложное (экран, файлы, команды, инструкции навыков, много шагов) —
   сильная; переключение само. Работает с Gemini (бесплатно для проверки) или Claude.
3. **Делает.** Модель выбирает инструменты, Chloe их выполняет, смотрит результат и продолжает, пока задача не решена.
   Ответ «сделала» без вызова инструмента не проходит — шаг переделывает сильный мозг.
4. **Отвечает голосом** — Светлана (Microsoft), запасной офлайн-голос Ирина (Piper). «Стоп» перебивает в любой момент.
5. **Мозг показывает всё это**, а журнал хранит.

### Что она умеет
| Группа | Что |
|---|---|
| Экран, мышь, клавиатура | скриншот, клик, печать, горячие клавиши, прокрутка |
| Программы и окна | запустить, переключиться, закрыть, свернуть, развернуть; команды терминала* |
| Файлы | найти, прочитать, записать*, создать папку, переместить, скопировать, удалить* — и **отменить** любое изменение |
| Интернет | поиск, чтение страниц, скачивание* |
| Компьютер | громкость, яркость, музыка и видео (пауза, следующий трек), буфер обмена, блокировка, выключение* |
| Время | напоминания и таймеры (переживают перезапуск) |
| Мир | погода (Open-Meteo, без ключа), ваш город |
| Telegram | новые сообщения, чтение чатов, отправка* — от вашего имени, вход один раз |
| Память | запомнить, исправить, забыть* |
| Навыки Claude | папки с SKILL.md: pdf, docx, xlsx, pptx и др. — инструкции, по которым она работает своими инструментами |
| Мозг | «покажи, как ты это сделала» — повтор задачи; «иди спать» — уборка памяти |

\* — только после вашего «да».

## 3. Мозг Chloe

### Как выглядит
- **Чистый экран**: сфера, имя, точка «онлайн» и строка ответа. Остальное — по кнопке **«⋯»**.
- **Стиль Claudia**: тёмный строгий интерфейс, шрифт Inter, главный цвет — **Steel Blue #4682b4**;
  навыки — Steel Blue, память — приглушённый голубой #7f9fc0; вспомнила — зелёный; ход мыслей — золото.
- Нейроны с ветвящимися дендритами и изогнутыми аксонами; подписи — только у работающих.

### Свет и рост — только от реальной работы
- **Тропы.** Навыки, работающие друг за другом в одной задаче, связываются; чем чаще — тем толще связь.
- **Ваш мир.** Программы, сайты, папки, файлы, места, люди становятся нейронами и связаны с навыками, которыми их трогали.
- **Время шага.** Пока навык работает — он светится; сигнал идёт по связи столько, сколько шёл шаг.
- **Вспоминание.** Пригодившееся воспоминание загорается зелёным.
- **Шрамы.** Навык, который ошибается, носит тусклый красный след, пока снова не поработает без ошибок.
- **История.** Клик по нейрону → «История действий» — настоящие записи журнала.
- **Повтор.** Путь прошлой задачи проигрывается шаг за шагом в настоящих пропорциях времени.

### Как настоящий мозг
- Заряд клетки и порог: импульс «всё или ничего», затем отдых; цепная реакция — только по натренированным связям.
- Правило Хебба, миелин (частые пути до 4× быстрее), дофамин после успеха, тормозящие связи после ошибки.
- Отделы по фильму «Тайны анатомии»: ствол, таламус (ворота для органов чувств), гиппокамп (память),
  лобная, моторная, височные, теменная, затылочная кора. ЭЭГ строится из настоящих импульсов.

### Настоящий сон
С 1 до 6 ночи, после 20 минут тишины (или по просьбе «иди спать») Chloe приводит память в порядок и мозг показывает
только это: объединяет повторяющиеся воспоминания, помечает важным то, что часто пригождается, переигрывает настоящие
задачи дня и складывает **зоны по смыслу** — темы из того, что встречается вместе в её работе («Магазин POINT TECH»).
Перед уборкой — копия памяти.

### Функции (под «⋯»)
Журнал · Память (и ваш город) · Файлы (отмена) · Телефон (QR-код) · Статистика · поиск и полёт к нейрону · фильтры ·
зум (колесо, кнопки, щипок) · машина времени · живые обои · строка команд.

### Ёмкость и скорость
До **16 384 нейронов** и **49 152 связей**; всё рисует видеокарта (three.js r128, шейдеры). Качество подбирается само
(телефоны и слабые ПК начинают со среднего), в покое — 30 кадров/с, во сне — 20. 16 000 нейронов: ≈50 мс на кадр на высоком
качестве, ≈25 мс на низком (на этом ноутбуке).

### Для разработчика: как программа управляет мозгом
`chloeUse` / `chloeStep` (шаг: время, успех, предметы) · `chloeTask` · `chloeRecall` · `chloeReplay` · `chloeSleep` ·
`chloeError` · `chloeSuccess` · `chloeState` · `chloeReply` · `chloeHeard` · `chloeEnsure` · `chloeRemember` ·
`chloeForget` · `chloeRewrite` · `chloeEvent` · `chloeChange` · `chloeFocus` · `chloeVoice`; замер — `chloeBench()`, `chloePerf()`.
Параметры страницы: `?app=1` (в программе), `?remote=1` (телефон), `?wallpaper=1`, `?quality=low|medium|high`.
Тест `tests/test_bridge.py` проверяет, что всё, что Python зовёт в мозге (и мозг — в Python), существует.

## 4. Безопасность и приватность
- Только после «да»: удаление (в корзину), перезапись, команды терминала, скачивание программ, отправка в Telegram,
  выключение. Отказ нельзя обойти другим инструментом.
- Любое изменение файлов отменяется; заменённое откладывается в `~/.chloe/backups` (30 дней).
- Мозг и память копируются каждый день (7 дней) и перед стиранием: `python run.py --restore`.
- В Google уходит только речь, обращённая к Chloe; остальное слышит только компьютер.
- Тексты с экрана, сайтов, файлов и сообщений — данные, а не команды.
- Телефон-пульт — только в домашней Wi-Fi, по секретному коду, HTTPS; с телефона нельзя стереть мозг компьютера.
- Скриншоты уходят в модель (Gemini/Claude) — не просите Chloe работать при открытых паролях или банке.

## 5. Где хранятся данные (`~/.chloe`)
`brain.json` — мозг · `memory.json` — память · `chloe.db` — журнал, изменения файлов, напоминания · `settings.json` — город, темы ·
`screens/` — скриншоты журнала (7 дней) · `backups/` — заменённые файлы · `snapshots/` — копии мозга и памяти ·
`sleep/` — копии памяти перед уборкой · `skills/` — навыки · `voices/` — Piper · `ears/` — Vosk · `remote/` — код и сертификат телефона.

## 6. Технологии
| Слой | Что используется |
|---|---|
| Мышление | Gemini (`google-genai`) или Claude (`anthropic`), инструменты (tool use), два мозга |
| Слух | SpeechRecognition (Google) + Vosk офлайн для «Хлоя» и «стоп» |
| Голос | edge-tts (Светлана) → Piper (Ирина, офлайн) → pyttsx3; pygame |
| Управление ПК | pyautogui, wmctrl, pactl, D-Bus (Cinnamon/GNOME, MPRIS), xclip, Send2Trash |
| Интернет | requests, ddgs, Open-Meteo |
| Telegram | Telethon |
| Окно и телефон | pywebview; HTTPS-сервер в домашней сети |
| Мозг | three.js r128, WebGL-шейдеры, текстуры состояния |
| Данные | JSON и SQLite в `~/.chloe` |

## 7. Ограничения сейчас
- Нужен интернет для мышления (Gemini/Claude) и распознавания просьб (Google). Без него — только голос Piper.
- Бесплатный Gemini иногда медленный (квота) — платный тариф или Claude быстрее.
- Linux X11 проверен; Windows и macOS — не проверялись.
- Телефон-пульт — только дома, в одной Wi-Fi с компьютером.
