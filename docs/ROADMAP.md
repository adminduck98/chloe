# Chloe — дорожная карта и история проекта

Chloe — личный ИИ-ассистент в стиле Jarvis. Управляется голосом, отвечает голосом и сама полностью
управляет компьютером (Windows, macOS, Linux). Её «мозг» виден на экране как живая нейронная сеть.

## Что лежит в этой папке

| Путь | Что это |
|---|---|
| `run.py` | Запуск: `python run.py` |
| `chloe/` | **Весь код Chloe** — по модулю на каждую часть (схема — в `docs/ARCHITECTURE.md`) |
| `chloe/ui/chloe-mind.html` | Живой мозг Chloe (открывается в окне программы; можно открыть и в браузере для демо) |
| `tests/` | Тесты: `.venv/bin/python -m unittest discover -s tests -t .` |
| `requirements.txt`, `README.md` | Установка и запуск |
| `design/` | Все прототипы ядра по шагам — от первой сферы до мозга |
| `design/screenshots/` | Скриншоты проверок |
| `archive/` | Первая версия `chloe.py` (терминальная) и хедер orbito, с которого всё началось |
| `docs/ROADMAP.md` | Этот файл |
| `docs/ARCHITECTURE.md` | Как устроен код и куда добавлять новое |

Данные Chloe на компьютере хранятся в `~/.chloe/`: `brain.json` (мозг), `memory.json` (что она о вас помнит),
`chloe.db` (журнал), `screens/` (скриншоты журнала).

## Принятые решения
- **Управление — голосом**, ответы — голосом. Строка ввода в окне — только запасной вариант.
- Chloe **сама** ищет, скачивает, создаёт, перемещает и удаляет файлы — пользователю ничего не нужно присылать.
- Необратимое — только после голосового «да»: удаление (в корзину), перезапись, команды терминала, скачивание программ.
  Отключается `CHLOE_CONFIRM=off`.
- Своя Chloe, а не готовый Leon; из Leon взяты идеи: режимы работы, структура навыков, память.
- Вид: **живая сфера из частиц, внутри — нейроны** (не терминал и не кольца-реактор).
- Всё, что знает и умеет Chloe, **видно в мозге** — ничего не прячется.

## Мозг: что уже сделано
- Нейроны с ветвящимися дендритами и изогнутыми аксонами; навыки — голубые, память — зелёная.
- Рост нового нейрона, сигналы по связям, укрепление связей от использования, угасание без него.
- Зоны-доли: Компьютер (ядро в центре), Интернет, Память, Люди, Работа, Магазин…
- Состояния без надписей: ждёт / слушает / думает / говорит / спит.
- Ход мыслей (золотая цепочка), ошибки (красные, связь перестраивается), настроение сферы.
- Поиск, полёт к нейрону, фильтры, статистика, машина времени, сон, живые обои, авто-качество.
- Масштаб: колесо, кнопки, щипок, перемещение.
- До 16 384 нейронов и 49 152 связей; всё рисует видеокарта.
- Естественный свет: волны и сигналы цвета сферы, без белых вспышек.

## Технологии
| Слой | Что используется |
|---|---|
| Мозг (мышление) | Gemini (`google-genai`, бесплатно для проверки) или Claude (`anthropic`), инструменты (tool use) |
| Слух | SpeechRecognition (Google), микрофон открыт всегда, слово «Хлоя», «стоп» |
| Голос | edge-tts (Светлана) + pygame; запасные — Piper (офлайн, Ирина), pyttsx3 |
| Управление | pyautogui, pyperclip, subprocess, shutil, Send2Trash |
| Интернет | requests, ddgs (поиск DuckDuckGo) |
| Окно | pywebview + страница мозга |
| Графика мозга | three.js (WebGL, шейдеры) |
| Память и журнал | память — JSON, журнал — SQLite в `~/.chloe` |

## Сделано (4–5 ноября 2026)
- Запуск на своём компьютере (Linux Mint), голос, окно, права.
- Мозг: Gemini (бесплатный) или Claude; при перегрузке Gemini — запасные модели.
- **Журнал** («ничего не скрыто») и **Память** (посмотреть, исправить, забыть) в окне мозга.
- **Перебивание «стоп»**, Chloe дослушивает фразу с паузами, не принимает свой голос за команду.
- Безопасность: подтверждение «да/нет» по целым словам, отказ нельзя обойти другим инструментом.
- Проект разложен по модулям (`chloe/`), git, тесты.
- **Модуль «Файлы» с отменой**: каждое изменение на диске видно в окне и отменяется (голосом тоже).
- **Telegram** (Telethon, от имени пользователя): новые сообщения, чтение чатов, отправка после «да»; вход — `--login-telegram`.
- **Надёжность**: копии мозга и памяти (день, перед сбросом), битый мозг не затирает хороший; тест связи Python ↔ мозг;
  описание, демо-мозг и скриншоты из параллельной версии перенесены.
- **Телефон-пульт**: мозг, голос и панели в браузере телефона по Wi‑Fi; HTTPS, вход по QR-коду, только безопасные методы.
- **Навыки Claude (SKILL.md)** с любой моделью: use_skill / read_skill_file, установка из папки или git, нейрон на навык.
- **Скорость мозга**: в видеокарту — только занятые строки, без пересчёта раскладки на подписях, мельче тела при толпе,
  упрощённые аксоны на среднем/низком качестве, 30/20 кадров в покое/сне, слабые устройства начинают со среднего.
- **Зоны по смыслу**: темы из совместной работы складываются во сне, нейроны переезжают в свою тему.
- **Настоящий сон**: ночью объединяет повторы в памяти, укрепляет важное, переигрывает задачи дня; мозг показывает только это.
- **Мозг — карта опыта**: тропы из совместной работы, нейроны программ/сайтов/папок, вспоминание зелёным, шрамы от ошибок,
  время шага в скорости сигнала, повтор задачи. Новый мозг пользователя (Steel Blue, анатомия, сон, ЭЭГ) слит с панелями.
- **Окна, музыка, буфер, питание, напоминания и таймеры** — свои инструменты вместо клавиш и мыши.
- **Ответ без действия не проходит**: «Выключаю», а инструмента нет — переделывает сильный мозг.
- **Слово «Хлоя» офлайн** (Vosk, 45 МБ): в Google уходит только сказанное Хлое, «стоп» во время работы — без интернета.
- **Громкость и яркость**: pactl и ползунок Cinnamon/GNOME; громкость 0–100, яркость не ниже 5%.
- **Город и погода**: Open-Meteo без ключа; город спрашивает сама, хранит в `settings.json`, меняется в панели «Память».
- **Два мозга**: быстрая модель для простого, сильная для экрана, файлов, команд и многих шагов — переключение само.
- **Офлайн-голос Piper** (Ирина) — запасной: если сервер Microsoft не отвечает, Chloe не переходит на робота.
  Основной голос — Светлана (выбор пользователя); Piper быстрее (0,3–1 с против 1–10 с) — `CHLOE_TTS=piper`.
