# Chloe — голосовой ассистент, который сам управляет компьютером

Говорите «Хлоя, …» — она слушает, думает, делает на компьютере что нужно и отвечает голосом.
В окне виден её живой мозг: каждое действие загорается в нём, новые знания вырастают новыми нейронами.

Сделана для Windows, macOS и Linux; проверена на Linux Mint (X11).

Полное описание — [docs/ОПИСАНИЕ.md](docs/ОПИСАНИЕ.md), устройство кода — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), план — [docs/ROADMAP.md](docs/ROADMAP.md).

## Что она умеет сама
- Искать в интернете, читать страницы и **скачивать** нужные файлы (по умолчанию в «Загрузки»).
- **Создавать** папки и файлы, **перемещать**, **копировать**, **переименовывать**, **удалять в корзину**.
- Открывать программы, сайты, файлы; кликать, печатать, нажимать клавиши, прокручивать.
- Постоянно видеть экран: раз в 2 секунды смотрит, какое окно открыто и что на нём, и к каждой просьбе прикладывает свежий кадр — «что это за ошибка?», «переведи вот это», «закрой это» работают сразу. Кадры только в памяти, на диск не пишутся. Окна с паролями, банками, инкогнито и входом в аккаунты не смотрит. «Хлоя, не смотри на экран» / «смотри на экран», «не смотри на почту», «что я делал последние полчаса». В шапке окна видно, что она сейчас видит; нажатие — выключить.
- Выполнять команды терминала.
- **Запоминать** важное о вас — память хранится между запусками.
- **Проекты**: «Хлоя, продолжим проект Chloe» — где проект сейчас (задачи, решения, цели, git и GitHub, документы о нём из базы знаний) и следующий шаг. Задачи: «добавь задачу…», «отметь сделанной», «что в работе»; «запиши, что мы решили…». Кнопка «Проекты» в окне — список проектов, задачи (сделать → в работе → готово), решения и цели. Хранится в `chloe.db` — попадает в копии дня.
- **Расшифровка аудио**: «Хлоя, расшифруй эту запись» — WAV, MP3, FLAC, OGG (с `ffmpeg` ещё M4A, голосовые Telegram, видео), любой длины; текст — рядом с файлом (.txt). Распознаёт Qwen, без него — Google.
- **База знаний из ваших документов**: «Хлоя, изучи файлы с рабочего стола» — PDF, Word, тексты, Markdown, HTML. Потом «что мы решили про голос?» — ответ по документам с источником (документ и страница). Файлы только читаются; «какие документы ты знаешь», «забудь документ 3». Хранится в `~/.chloe/chloe.db` и попадает в ежедневные копии.

Ничего присылать ей не нужно — она всё делает сама.

## Безопасность
**Карта прав (кнопка «Доступ» в окне)**: экран, чтение и изменение файлов, команды, мышь и клавиатура, интернет, Telegram, телефон, Google Calendar, картинки и видео, память, база знаний, питание — у каждой «разрешено / спрашивать / запрещено» и сколько раз за неделю Chloe этим пользовалась. **Private Vault** — приватные папки: внутрь Chloe не заглядывает (не читает, не ищет, не изучает, не меняет, окна с ними не смотрит). Голосом: «что тебе разрешено?», «запрети читать Telegram», «сделай папку Личное приватной». Усилить защиту — сразу, ослабить — только после «да, делай»; с телефона права не меняются. Хранится в `~/.chloe/permissions.json`.

Необратимые действия Chloe делает только после вашего голосового «да»:
удаление (в корзину), перезапись файла, команды терминала, скачивание и запуск программ (.exe, .dmg, .sh, .py…),
запись в автозапуск, скрытые папки настроек и за пределы домашней папки.
Домашнюю папку, Рабочий стол, Документы и Загрузки целиком удалить нельзя.
Аварийная остановка мыши — резко увести курсор в левый верхний угол экрана.
Кадры экрана уходят в модель (Qwen, Claude или Gemini) через API вместе с просьбой. Приватные окна (пароли, банки, инкогнито) Chloe пропускает сама, но список не идеален: добавьте свои слова — «Хлоя, не смотри на …» — или выключите зрение кнопкой в шапке. На Linux для названия окна нужен `xdotool` (или `xprop`); на macOS — разрешение «Запись экрана» и «Универсальный доступ».

## Установка
1. Python 3.10+.
2. Системные пакеты:
   - **Windows:** ничего дополнительно.
   - **macOS:** `brew install portaudio`, затем `pip install pyobjc`.
   - **Linux:** `sudo apt install portaudio19-dev python3-dev python3-tk espeak-ng xclip libgirepository1.0-dev gir1.2-webkit2-4.1`
3. Зависимости: `pip install -r requirements.txt`
4. Запасной офлайн-голос (если сервер Microsoft не ответит, ~60 МБ): `python run.py --install-voice`
5. Офлайн-слово «Хлоя» (~45 МБ): `python run.py --install-ears` — без него вся речь в комнате уходит в Google
6. Telegram (по желанию): `python run.py --login-telegram` — см. раздел «Telegram»
7. Ключ одного из «мозгов» — Chloe сама выберет, какой задан (порядок: Qwen → DeepSeek → Claude → Gemini):
   - **Qwen** (Alibaba, основной) — ключ на qwencloud.com → API Keys. Ключ привязан к региону: по умолчанию Сингапур,
     другой — `QWEN_BASE_URL` (адрес из раздела Regions and endpoints):
     `export DASHSCOPE_API_KEY="ваш_ключ"`
   - **DeepSeek** — ключ на platform.deepseek.com → API keys:
     `export DEEPSEEK_API_KEY="ваш_ключ"`
     Если заданы оба, думает Qwen, а DeepSeek — запасной: подхватывает, когда Qwen занят или недоступен.
     DeepSeek картинок не видит — скриншоты разбирает только Qwen.
   - **Claude** — ключ на console.anthropic.com (`sk-ant-…`): `export ANTHROPIC_API_KEY="ваш_ключ"`
     Вместе с Qwen или DeepSeek Claude не заменяет их, а помогает: простые просьбы — DeepSeek/Qwen,
     сложные и всё, где нужен экран, — Claude Haiku 5.5 (`claude-haiku-5-5`); он же подхватывает,
     когда основной мозг недоступен. Для голоса Claude думает быстро: без раздумий, effort low.
   - **Gemini** — ключ на aistudio.google.com: `export GEMINI_API_KEY="ваш_ключ"`
   Ключи — в `~/.config/chloe/keys.env` (строками `DASHSCOPE_API_KEY=…`, права 600: `chmod 600 ~/.config/chloe/keys.env`). Windows PowerShell: `$env:DASHSCOPE_API_KEY="ваш_ключ"`.

## Запуск
```
python run.py               # окно с мозгом + голос
python run.py --fullscreen  # мозг на весь экран
python run.py --no-window   # только голос
python run.py --text        # без микрофона, с клавиатуры (для проверки)
```
Говорите: «Хлоя, скачай последнюю версию VLC», «Хлоя, создай на рабочем столе папку Отчёты и перенеси туда все PDF из Загрузок».
После ответа 30 секунд можно говорить без слова «Хлоя». «Стоп» — перебить на полуслове (и во время работы),
«Выключись» — закрыть. Можно говорить с паузами: Chloe дослушает фразу до конца.
Можно и написать команду в строке внизу окна.

**Запуск вместе с компьютером**: `.venv/bin/python run.py --autostart on` — Chloe стартует сама через 10 секунд после входа
в систему (`--autostart off` — выключить, `status` — узнать). Что она печатала бы в терминал — в `~/.chloe/chloe.log`.
Вторая копия не запустится: если Chloe уже работает, `./start.sh` просто скажет об этом и выйдет.

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что делает |
|---|---|---|
| `CHLOE_PROVIDER` | по ключу | `qwen`, `deepseek`, `anthropic` или `gemini` — кто думает |
| `CHLOE_MODEL_FAST` | `qwen3.8-flash` / `deepseek-flash` / `claude-haiku-5-5` / `gemini-3.5-flash-lite` | быстрый мозг — для простых просьб |
| `CHLOE_MODEL_STRONG` | `qwen3.8-flash+thinking` / `deepseek-v4-pro` (с ключом Claude — `claude-haiku-5-5`) / `claude-sonnet-5-5` / `gemini-3.5-flash` | сильный мозг — для экрана, файлов, команд, текстов, многих шагов |
| `CHLOE_MODEL` | — | одна модель на всё, без переключения; если модель перегружена, Chloe сама берёт запасную; `+thinking` — та же модель Qwen с раздумьями |
| `CHLOE_LANG` | `ru-RU` | язык распознавания (`uz-UZ`, `en-US`) |
| `CHLOE_TTS` | `edge` | `edge` — Светлана (Microsoft, нужен интернет); `piper` — офлайн-голос, озвучка за доли секунды; `svetlana` — только Светлана: без интернета Chloe молчит, ответ виден в окне; `qwen` — голос Qwen (`CHLOE_QWEN_VOICE`, по умолчанию `longanlingxin`), не ответил — Светлана |
| `CHLOE_ASR` | `google` | слух: `google` — быстрее (0,6–1,5 с); `qwen` — распознавание Qwen (2–4,5 с) (лучше с английскими названиями посреди русской речи), спрашивается вместе с Google; Qwen ждём `CHLOE_QWEN_ASR_WAIT` = 3,5 с, потом берём Google |
| `CHLOE_VOICE` | `ru-RU-SvetlanaNeural` | голос Microsoft, например `en-US-AvaMultilingualNeural` (многоязычная Ava) или `uz-UZ-MadinaNeural` |
| `CHLOE_STREAM_VOICE` | `on` | `on` — Светлана начинает говорить с первого кусочка звука, не дожидаясь всей фразы (нужен `miniaudio`); `off` — целым файлом, как раньше |
| `CHLOE_PIPER_VOICE` | `ru_RU-irina-medium` | офлайн-голос: запасной, когда Microsoft не отвечает, или основной при `CHLOE_TTS=piper`; русские: irina (жен.), denis, dmitri, ruslan |
| `CHLOE_CONFIRM` | `safe` | `off` — не спрашивать подтверждений (на свой риск) |
| `CHLOE_PAUSE` | `1.5` | пауза (сек), после которой фраза считается законченной; у длинной речи (от 8 слов) — на 0,8 с дольше; больше — можно говорить медленнее |
| `CHLOE_CONTINUE` | `60` | сколько секунд после «Хлоя» принимается продолжение одной просьбы (длинная диктовка) |
| `CHLOE_PHRASE` | `40` | самая длинная фраза (сек) |
| `CHLOE_ACTIVE` | `45` | сколько секунд после ответа можно говорить без слова «Хлоя» |
| `CHLOE_KEEP_SCREENS` | `7` | сколько дней хранить скриншоты в журнале; `0` — не хранить |

## Тесты
```

```

## Что уходит в интернет
Слово «Хлоя» Chloe узнаёт сама, на компьютере. В Google на распознавание уходит только сказанное ей: фраза со словом «Хлоя»
и её продолжение, ответ в течение 45 секунд после её реплики (`CHLOE_ACTIVE`), «да/нет» на её вопрос.
Пока она работает, «стоп» узнаётся офлайн; в Google — только короткие фразы (до 2,5 с), если офлайн не расслышал.
Остальная речь в комнате не покидает компьютер — в консоли видно: «[не Хлое — не отправлено: …]».
`CHLOE_WAKE=cloud` — как раньше, всё в Google.

## Резервные копии
Мозг, память, напоминания с журналом (`chloe.db`) и выученные навыки копируются каждый день (хранятся 14 дней, три последние копии — всегда) и перед «Сбросить мозг» — в `~/.chloe/snapshots/`.
Расход за сегодня виден в шапке окна (`сегодня $…`); нажатие открывает ядро с подробностями.
Битый или пустой мозг хороший никогда не затирает. Вернуть (при закрытой Хлое):
`python run.py --restore` — список копий, `python run.py --restore 2026-11-05` — вернуть этот день.

## Где хранится
Папка `~/.chloe`: `brain.json` — мозг (нейроны и связи), `memory.json` — что Chloe о вас запомнила,
`chloe.db` — журнал: всё, что она услышала, сказала и сделала, `screens/` — скриншоты из журнала,
`voices/` — офлайн-голоса Piper, `ears/` — офлайн-слух Vosk, `settings.json` — ваш город, `backups/` — файлы, которые Chloe заменила (для отмены, 30 дней).

## Память — что Chloe знает о вас
Кнопка «Память» в окне: все воспоминания с датой. Можно добавить своё, исправить текст или забыть —
нейрон воспоминания исчезает из мозга вместе со связями. То же из карточки зелёного нейрона: «Изменить», «Забыть».
Голосом: «Хлоя, забудь, что…» — забывает только после вашего «да». Каждое изменение памяти видно в журнале.

## Telegram
«Хлоя, что нового в Телеграме?», «прочитай, что написала мама», «напиши Ахмеду, что я задержусь».
Хлоя работает с Telegram от вашего имени — как ещё одно ваше устройство (в списке устройств оно называется «Chloe»).

**Войти один раз** — сами, в своём терминале:
1. Откройте https://my.telegram.org, войдите по номеру, выберите «API development tools» и создайте приложение
   (название любое, например Chloe). Там будут `api_id` (число) и `api_hash` (длинная строка).
2. В папке проекта: `.venv/bin/python run.py --login-telegram` — введите `api_id`, `api_hash`, номер телефона и код из Telegram.

Безопасность: ключи и вход хранятся только у вас — `~/.chloe/telegram.json` и `~/.chloe/telegram.session`
(доступ только владельцу; эти файлы — как пароль, никому их не давайте). Хлоя не видит ни номер, ни код.
Читает без вопросов и **ничего не отмечает прочитанным**. Отправляет только по вашей просьбе и только после «да»:
переспрашивает, кому и что. Если похожих чатов несколько («Ахмед Каримов» и «Ахмед Работа») — уточнит, не угадывая.
Новые сообщения смотрит в личных чатах и группах; каналы и чаты без звука — только если попросите.
Выйти: Telegram → Настройки → Устройства → завершить сеанс «Chloe»; и удалить два файла выше.

## Окна, музыка, буфер, питание, напоминания
- Окна: «переключись на Телеграм», «закрой Firefox», «сверни всё в Документах», «закрой все окна» (спросит «да/нет»).
- Музыка и видео в любом плеере и в браузере: «пауза», «следующий трек», «что сейчас играет?».
- Буфер обмена: «что у меня в буфере?», «скопируй это».
- Питание: «заблокируй экран», «выключи / перезагрузи компьютер», «спящий режим» — последние три только после вашего «да».
- Напоминания: «поставь таймер на 5 минут», «напомни в 18:30 позвонить маме», «какие напоминания?», «отмени второе».
  Хлоя скажет вслух и покажет уведомление; напоминания переживают перезапуск (таблица `reminders` в `chloe.db`).

## Громкость и яркость
«Хлоя, погромче», «громкость на 30», «выключи звук», «сделай экран темнее», «яркость на максимум».
Громкость не выше 100%; яркость не ниже 5%, чтобы экран не погас. Если звук выключен, Хлоя отвечает текстом в окне.

## Погода
«Хлоя, какая погода?», «будет ли завтра дождь?», «погода в Москве на выходные». Данные Open-Meteo — бесплатно, без ключа.
Город Chloe спросит сама один раз и запомнит; сменить — «Хлоя, я теперь живу в …» или поле «Город» в панели «Память».

## Файлы — всё можно отменить
Кнопка «Файлы» в окне: всё, что Chloe меняла на диске — создала, перезаписала, переместила, скопировала,
удалила в корзину, скачала. У каждого изменения — «Отменить» и «Открыть папку». Голосом: «Хлоя, отмени последнее».
Отмена ничего не стирает насовсем: лишнее уходит в Корзину, а файл, который Chloe заменила, перед заменой
откладывается в `~/.chloe/backups` (30 дней) и при отмене возвращается. Удалённое возвращается из Корзины (Linux).

## Мозг — карта реального опыта

**Живое ядро.** Мозг — два полушария с извилинами (голограмма: светятся края и борозды), между ними — ядро,
источник активности Chloe. Вокруг ядра — четыре слоя-орбиты: **Мышление** (горит, пока думает), **Память**
(запомнила, вспомнила), **Процессы** (работают инструменты), **Данные** (файлы, сайты, загрузки) — чем больше
работы, тем быстрее крутится и ярче светится слой. Ядро бьётся как сердце (чаще, когда думает), от него к коре
летят импульсы, мозг медленно дышит и слегка покачивается.

**Центр управления.** Подписи в мозге — кнопки: «Ядро» открывает состояние всей системы (что делает сейчас,
слои, подключённые модели, расход за сегодня, зрение, память, навыки, напоминания); слои и отделы открывают свой
слой системы — «Память» → память, «Действия» и «Процессы» → журнал, «Интернет» и «Данные» → файлы.
На телефоне — то же самое.
Мозг светится и растёт только от настоящей работы Chloe:
- **Тропы.** Навыки, которые работают друг за другом в одной задаче, связываются; чем чаще вместе — тем толще и быстрее связь
  («Поиск в интернете» → «Загрузки» → «Управление файлами»).
- **Ваш мир.** Программа, сайт, папка, файл, город, человек, с которыми Chloe поработала, становятся нейронами в своих зонах
  («Программы», «Сайты», «Папки», «Места», «Люди») и связываются с навыками, которыми она их трогала.
- **История.** Клик по нейрону → «История действий»: настоящие действия из журнала — что, когда, получилось ли.
- **Время шага.** Пока навык работает, он светится; сигнал идёт по связи столько, сколько шёл шаг (скачивание медленно, клик быстро).
- **Вспоминание.** Воспоминание, которое пригодилось в ответе, загорается зелёным (и пишется в журнал «Вспомнила: …»).
- **Шрамы.** Навык, который ошибается, носит тусклый красный след; он сходит, когда навык снова работает без ошибок.
- **Настоящий сон.** С 1 до 6 ночи, после 20 минут тишины (или по просьбе «Хлоя, иди спать»), Chloe приводит память в порядок:
  объединяет повторы («Любит кофе» + «Любит чёрный кофе без сахара» → остаётся полное), помечает важным то, что за месяц
  пригодилось 2+ раза (оно всегда в подсказке), и переигрывает настоящие задачи дня. Мозг показывает только это —
  без придуманных вспышек; в строке состояния видно, что она делает. Перед уборкой копия памяти — в `~/.chloe/sleep/`,
  каждое объединение — в журнале.
- **Зоны по смыслу.** Во сне Chloe смотрит, что встречается вместе в её настоящих задачах за месяц — сайты, папки,
  программы, люди, места и пригодившиеся воспоминания, — и складывает из этого темы (например, «Магазин POINT TECH»).
  Название придумывает быстрая модель (или берётся самое частое слово просьб); тема, которая почти не изменилась,
  имя сохраняет. Нейроны темы переезжают в свою область коры, воспоминания получают зону темы (видно в «Памяти»),
  новые предметы этой темы сразу растут там. Навыки остаются на своих местах. Каждая новая тема — в журнале.
- **Повтор.** «Хлоя, покажи, как ты это сделала» — мозг проигрывает путь прошлой задачи шаг за шагом в настоящих пропорциях времени.

## Google Calendar
«Что у меня завтра?», «добавь встречу в пятницу в три», «удали встречу с Тимуром». Добавление и удаление — с подтверждением.
Вход — через Google в браузере (пароль Chloe не видит), доступ только к событиям. Нужен свой OAuth client (тип Desktop app)
из Google Cloud Console: файл `~/.config/chloe/google_client.json`; затем «Хлоя, подключи календарь». «Отключи календарь» — доступ отзывается.

## Телефон Android (adb)
«Что на экране телефона?», «открой Telegram на телефоне», «напечатай…», «покажи экран телефона» (окно scrcpy).
Нужно: `sudo apt install adb scrcpy`, на телефоне «Для разработчиков» → «Отладка по USB»; на Xiaomi для нажатий ещё
«Отладка по USB (настройки безопасности)». Русский текст печатается через клавиатуру ADBKeyBoard (ставится на телефон один раз).

## Картинки и видео (Qwen)
«Хлоя, нарисуй…», «сделай фон на этой картинке синим», «сделай видео…», «оживи эту картинку». Работает в фоне: Chloe скажет,
когда готово, и откроет файл. Картинки — `~/Изображения/Chloe` (около минуты, ~0,25 % месячного Token Plan), видео —
`~/Видео/Chloe` (3–15 с; 5 с 720P ≈ 4,5 % пакета — перед видео Chloe называет цену и спрашивает). Модели:
`CHLOE_IMAGE_MODEL` (qwen-image-3.0-pro), `CHLOE_VIDEO_MODEL` (happyhorse-1.1-t2v), `CHLOE_I2V_MODEL` (happyhorse-1.1-i2v).

## Ролик из идеи (Creative Studio)
«Хлоя, сделай ролик о…» — она сама пишет сценарий (3–6 сцен: кадр и закадровая фраза), рисует кадры, озвучивает
Светланой и склеивает mp4 в `~/Видео/Chloe`. По умолчанию — слайды с плавным движением камеры: 3 сцены ≈ минута работы
и ~0,8 % месячного пакета Qwen. «Живое видео» (каждый кадр оживает) — в разы дороже, только по просьбе. Перед началом
Chloe называет цену и сцены и ждёт «да». Форматы: 16:9, 9:16 (для телефона), 1:1. ffmpeg ставится вместе с Chloe
(пакет `imageio-ffmpeg`), sudo не нужен.

## Озвучка и аудиокниги (Voice Studio)
«Хлоя, сделай аудиокнигу из этой книги», «озвучь этот документ», «прочитай статью в файл мужским голосом, побыстрее».
Читает PDF, Word, EPUB, FB2, TXT, Markdown, HTML; чистит переносы, номера страниц и ссылки. Книга с главами
(«Глава 1», «Часть вторая», «Пролог») — по mp3 на главу в своей папке, иначе один файл. Всё — в `~/Музыка/Chloe`.
Голоса: Светлана (по умолчанию) и Дмитрий — бесплатные голоса Microsoft; qwen — голос Qwen (тратит кредиты, спрашивает).
Скорость 0,5–2. Больше 30 минут звука — сначала спрашивает. Работает в фоне, скажет, когда готово.

## Новости и утренняя сводка (World Intelligence)
«Что нового?», «что в мире?», «новости Узбекистана», «что нового в технологиях», «новости про курс сума».
Свежие (за сутки) заголовки из открытых RSS: главное — BBC, Meduza, РБК, ТАСС (разные взгляды, у каждой новости —
источник); Узбекистан — Газета.uz, Kun.uz, Podrobno.uz; экономика — РБК, Ведомости, Spot.uz; технологии — Хабр, 3DNews.
Новость, о которой пишут несколько изданий, — выше. Любая своя тема — через поиск новостей. Темы сводки: «следи за
экономикой и технологиями». «Доброе утро» / «утренняя сводка» — дата, погода, календарь, напоминания и 3–5 главных
новостей за минуту. «Рассказывай сводку по утрам» — при первом запуске с 5 до 12 Chloe расскажет её сама (с автозапуском —
сразу после включения компьютера); «не рассказывай сводку» — выключить.

## Финансы: подписки и платежи
«Добавь подписку Netflix 9 долларов, списание 15-го», «интернет 150 тысяч сумов в месяц», «сколько я трачу на подписки?»,
«что спишется на этой неделе?», «убери Spotify». Сумма в месяц — в сумах и долларах по курсу ЦБ Узбекистана (cbu.uz).
За день до списания Chloe напомнит: при запуске и в утренней сводке. Прошедшая дата сама переносится на следующий месяц
(год, неделю). Это только ваши записи (таблица `fin_subs` в `~/.chloe/chloe.db`): к банку Chloe не подключается,
номера карт не хранит, отменить подписку на сайте сервиса — ваше дело.

## Соцсети: контент-план и посты
«Придумай посты на неделю для моего канала», «сделай пост для Instagram про новую стиральную машину», «покажи план»,
«опубликуй пост 3», «выложи пост 5 завтра в 10 утра». Chloe пишет тексты в стиле сети, картинки и ролики делает сама
(create_media, make_film), всё сохраняет черновиками.
- **Telegram-канал** — публикует сама, от вашего имени, только в канал, где вы админ, и только после «да» на конкретный
  текст. Запланированный пост уходит сам, если вы его одобрили; изменили текст — одобрить заново.
- **Instagram, YouTube, TikTok** — готовит пакет (подпись с хэштегами и файлы) в `~/Документы/Chloe/Посты`, открывает
  папку и страницу загрузки; выкладываете вы, потом «опубликовала пост N». В срок — напоминает.
Медиа из приватных папок (Private Vault) не выкладываются. Хранится в `~/.chloe/chloe.db` (таблица `soc_posts`).

## Самочувствие (System State)
«Как ты?», «всё ли работает?» — быстрая самопроверка без сети; «проверь себя» — глубокая (~5 с): каждый мозг отвечает
одним словом, голос Светланы, Google Calendar, Telegram, телефон, остаток пакета Qwen, интернет. Плюс автозапуск, место
на диске, копии памяти, ffmpeg, версия, ошибки за сутки (отказы и срабатывания защиты — не ошибки), карта прав.
В окне — раздел «Самочувствие» в панели «Ядро» (обновляется сам, кнопка «Проверить глубже»); если что-то сломано,
у надписи «Ядро» на мозге загорается точка. Значения ключей нигде не показываются. Последний результат — `~/.chloe/state.json`.

## Связи и история (Knowledge & Memory)
«Что связано с Voice Studio?», «откуда эта идея?», «какие документы относятся к задаче 27?», «что мы делали на этой
неделе?», «свяжи этот документ с задачей…». Граф строится из того, что уже хранится: проекты, задачи, решения, идеи, цели,
изученные документы, воспоминания. Связи: «в проекте», найденные сами (по общим редким словам — причина всегда названа)
и добавленные вручную; лишнюю авто-связь можно убрать, она не вернётся. Timeline — те же объекты по времени.
В окне — кнопка «Связи»: вкладка «История» и вкладка «Граф» (поиск, самые связанные, карточка объекта со схемой связей,
«×» — убрать связь). Свои таблицы — `graph_links` и `graph_hidden` в `~/.chloe/chloe.db`.

## Кредиты Qwen Token Plan
«Сколько осталось кредитов Qwen?» Точный процент и дата обновления — через Bailian CLI (`bl auth login --console
--console-site international`, один раз). При 80 % и 95 % Chloe предупреждает при запуске; если пакет исчерпан — говорит
один раз и отвечает через запасную модель. Папка `~/.bailian` (вход Alibaba) для инструментов Chloe закрыта, как и ключи.

## Телефон — пульт Хлои
Хлоя работает на компьютере, а телефон — её пульт: живой мозг, голос, Журнал, Память, Файлы с отменой.
1. Телефон и компьютер — в одной Wi‑Fi.
2. В окне Хлои: «⋯» → «Телефон» → отсканируйте QR-код телефоном.
3. Браузер один раз предупредит о сертификате (он свой, домашний: HTTPS нужен для микрофона) — «Дополнительно» → «Перейти».
4. Разрешите микрофон; меню браузера → «Добавить на главный экран» — будет как приложение.

Внизу: 🎤 — сказать (или напечатать), 🔊 — озвучивать ответы на телефоне. Подтверждения «да/нет» можно сказать и с телефона.
Без кода сервер не отдаёт ничего, кроме самой страницы; с телефона нельзя сохранить или стереть мозг компьютера.
Код — ключ от Хлои, не пересылайте его; новый: `python run.py --new-phone-key`. Выключить: `CHLOE_PHONE=off`; порт — `CHLOE_PHONE_PORT` (8770).
Если телефон не подключается — проверьте брандмауэр (`sudo ufw allow 8770/tcp`). Вне дома пока не работает.

## Обучение словами
- **«Запомни, как это делается»** (после задачи) — Хлоя записывает свой путь как навык: в следующий раз сразу по шагам,
  без поиска и лишних скриншотов. Не сработал шаг — найдёт другой путь и обновит навык.
- **Сценарии: «Когда я говорю „работаем“ — открой проект chloe, закрой ютуб, включи музыку»** — потом достаточно
  сказать «Хлоя, работаем».
- **Правила: «Неправильно, ютуб всегда открывай в Firefox»**, «впредь отвечай короче» — правило попадает в каждую
  подсказку. «Забудь правило 2» — убирает.
- «Чему ты научилась?» — список. Выученные навыки — обычные папки в `~/.chloe/skills` (можно открыть, поправить, удалить),
  правила — в `~/.chloe/settings.json`.

## Память, слух и расходы
- **Краткосрочная память** — последние реплики разговора за несколько часов (из журнала), в том числе до перезапуска:
  «как я говорил», «продолжи», «это» — Хлоя понимает, о чём речь. **Долгосрочная** — факты о вас (`remember`).
- **Речь в комнате** — то, что сказано не Хлое, тоже записывается в журнал (офлайн-распознавание Vosk, только на этом
  компьютере, в Google не уходит; хранится `CHLOE_OVERHEAR_DAYS` = 7 дней). Модели она отдаётся только когда вы спросите:
  «о чём мы говорили», «что я сказал про машину» (инструмент `conversation_log`). Выключить — `CHLOE_OVERHEAR=off`.
  Если дома есть другие люди — предупредите их.
- **Мышление** (DeepSeek + Claude): простое — DeepSeek Flash, экран, команды, файлы, тексты и ошибки —
  Claude Haiku 5.5 (видит экран, быстрый, в ~17 раз дешевле Sonnet; без раздумий, effort low).
  Нужен Sonnet — `CHLOE_MODEL_STRONG=claude-sonnet-5-5`: тогда экран смотрит Haiku («глаза»), а Sonnet берёт сложное.
  Модели уходят только два последних скриншота и в JPEG (в 8 раз легче PNG).
- **Расходы** — «Хлоя, сколько мы сегодня потратили?» (инструмент `brain_usage`): запросы, токены и примерная стоимость
  по каждой модели, `~/.chloe/usage.json`. Точный счёт — в кабинетах Anthropic и DeepSeek.

## Мои проекты
«Хлоя, как мои проекты?», «что с проектом nexus?», «что зависло?», «что делать дальше по chloe?».
Хлоя видит папки с git в `~/Документы`, `~/Documents`, `~/Projects` и т. п. (свои — через `CHLOE_PROJECTS`,
пути через `:`) и ваши репозитории на GitHub (через `gh`, вход — `gh auth login`): последняя активность,
незакоммиченное и неотправленное, открытые задачи и PR, что не трогали больше 14 дней.
Смотреть — без вопросов (инструмент `projects` только читает); закоммитить, отправить, завести задачу — только
по вашей просьбе и после «да». Как отвечать — навык `skills/my-projects`.

## Навыки в формате Claude (SKILL.md)
Chloe понимает навыки Claude (Agent Skills) — с любой моделью, и с Gemini тоже. Навык — папка с `SKILL.md`:
шапка `name` / `description` и инструкция. В подсказку попадают только имена и описания; полную инструкцию Chloe читает
инструментом `use_skill`, когда просьба подходит, и делает по ней своими инструментами (по инструкции навыка думает
сильный мозг). Скрипты навыка запускаются через `run_command` — только после вашего «да». Каждый навык — нейрон в зоне «Навыки».

- Свои навыки: `~/.chloe/skills/<имя>/SKILL.md`. Встроенные — в `skills/` проекта (пример: `morning-brief` — утренняя сводка).
- Добавить: `python run.py --add-skill <папка или git-ссылка>`, например все навыки Anthropic:
  `python run.py --add-skill https://github.com/anthropics/skills` (20 навыков: pdf, docx, xlsx, pptx…).
  Некоторым нужны Python-библиотеки (pypdf, python-docx…) — если их нет, Chloe скажет.
- Убрать навык — удалить его папку.

## Скорость мозга
Мозг сам подбирает качество под компьютер (телефон и слабый ПК начинают со среднего); вручную — `?quality=low|medium|high`.
В покое он рисует 30 кадров в секунду, во сне — 20; при любом действии — сразу полную частоту.
Замер на этом ноутбуке, мс на кадр вместе с видеокартой (`chloeBench()` в консоли страницы), до → после:

| Нейронов | высокое | низкое (после) |
|---|---|---|
| 11 | 16,5 → 7,3 | 4,1 |
| 2 000 | 28 → 24 | 14 |
| 8 000 | 43 → 25 | 20 |
| 16 000 | 92 → 50 | 25 (≈40 кадров/с) |

## Журнал — ничего не скрыто
Кнопка «Журнал» в окне: каждая просьба и всё, что Chloe сделала в ответ — какой инструмент, что передала,
что получила, сколько заняло, что видела на экране, что вы ответили на подтверждение. Поиск по журналу;
клик по нейрону → «История действий» показывает историю только этого навыка.
Записи можно смотреть и удалять (по одной или весь журнал), но не изменять.
Пишутся только фразы, обращённые к Chloe; остальная речь в комнате не сохраняется (но уходит в Google на распознавание).

## Ограничения
- Нужен интернет: Gemini или Claude, распознавание речи Google и голос Светланы (Microsoft) работают онлайн.
  Если Светлана не отвечает, Chloe говорит офлайн-голосом Piper, а без него — системным (pyttsx3).
- Linux: мышь и скриншоты работают в X11; в Wayland часто нужен вход в сеанс X11.
- macOS: дайте Терминалу права «Микрофон», «Запись экрана» и «Универсальный доступ».
